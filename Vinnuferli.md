# Vinnuferli

## Hópavinna og geymsla 

Í hópnum eru Edil Inga Kristjánsdóttir og Gabríel Orri Karlsson.

Verkefnið var unnið í sameiginlegri GitHub-geymslu: https://github.com/edilinga/HBV301G-Verkefni-4.git

Báðir hópmeðlimir unnu í geymslunni með Git og GitHub og lögðu sitt af mörkum með commit, push og pull request.

## Verkaskipting
Við skiptum verkefninu á milli okkar þannig að Gabríel vann að vinnuferli.md og use.case.md, en Edil vann að requirements.md og elicitation-plan.md. Við unnum því að mestu sjálfstætt að okkar skjölum en ræddum saman um verkefnið til að tryggja að skjölin tengdust og væru í samræmi við hvert annað.

Hópmeðlimir unnu að sínum verkefnum á aðskildum greinum. Breytingar voru vistaðar með commit og síðan push-aðar á GitHub. Pull request voru stofnuð fyrir breytingarnar áður en þær voru sameinaðar við aðalgrein verkefnisins.

Við fórum yfir vinnu hvors annars í gegnum pull request og gerðum breytingar eftir þörfum áður en efnið var sameinað við aðalgreinina.

## Ígrundun
Hópavinnan gekk mjög vel í þetta skipti og verkaskiptingin var skýr frá upphafi. Við skiptum verkefninu á milli okkar þannig að hvort okkar sá um ákveðna hluta og gátum því unnið sjálfstætt. Samskiptin gengu líka vel og við létum hvort annað vita þegar við vorum búin með okkar hluta.

Git og GitHub nýttust vel til að halda utan um verkefnið. Við notuðum aðskildar greinar og pull requests til að fara yfir vinnu hvors annars áður en breytingarnar voru sameinaðar. Í þetta skipti þurftum við ekki að gera neinar breytingar á skjölum hvors annars þar sem allt var í góðu lagi við yfirferðina. Vinnuferlið gekk því betur og var orðið auðveldara fyrir okkur að nota GitHub.

Það sem við gætum helst bætt næst er að setja okkur skýrari tímamörk fyrir hvern hluta verkefnisins og gefa okkur meiri tíma í sameiginlega yfirferð. Í heildina gekk verkefnið þó betur en síðast og við vorum orðin öruggari í vinnubrögðunum.
